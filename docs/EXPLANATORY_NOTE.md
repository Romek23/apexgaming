# Пояснювальна записка

## Тема роботи

Розробка вебзастосунку інтернет-магазину ігрових комп'ютерів ApexGaming.

## Вступ

Сучасний ринок комп'ютерної техніки активно розвивається завдяки зростанню попиту на ігрові комп'ютери, робочі станції та комплектуючі для високопродуктивних систем. Користувачам важливо швидко переглядати готові конфігурації, порівнювати характеристики, підбирати компоненти та мати зручний спосіб взаємодії з магазином.

Метою дипломної роботи є створення вебзастосунку ApexGaming, який поєднує клієнтську частину для перегляду товарів і збірок, серверну частину для обробки авторизації користувачів та базу даних для збереження інформації. Проект орієнтований на демонстрацію повного циклу розробки вебсистеми: від побудови інтерфейсу до реалізації API, підключення бази даних і підготовки запуску через Docker.

## Актуальність теми

Інтернет-магазини залишаються одним із найпоширеніших типів вебзастосунків, оскільки вони дають можливість продавати товари без прив'язки до фізичної точки продажу. Для магазину ігрових комп'ютерів особливо важливими є візуальна презентація, зрозуміла навігація, адаптивність інтерфейсу, швидкість роботи та можливість персоналізації користувацького досвіду.

Розробка такого проекту є актуальною, тому що вона охоплює практичні навички фронтенд- і бекенд-розробки, роботу з базою даних, створення REST API, базову безпеку авторизації та контейнеризацію середовища. Ці навички відповідають сучасним вимогам до розробників вебзастосунків.

## Мета і завдання роботи

Мета роботи: розробити повноцінний вебзастосунок інтернет-магазину ігрових комп'ютерів із сучасним інтерфейсом, авторизацією користувачів та серверною частиною.

Для досягнення мети були поставлені такі завдання:

1. Проаналізувати предметну область інтернет-магазину ігрових комп'ютерів.
2. Визначити функціональні та нефункціональні вимоги до системи.
3. Спроектувати структуру клієнтської та серверної частин.
4. Реалізувати адаптивний користувацький інтерфейс.
5. Реалізувати каталог товарів, головну сторінку та сторінку конструктора ПК.
6. Реалізувати реєстрацію, вхід користувача та збереження профілю.
7. Налаштувати взаємодію фронтенду з бекендом через HTTP API.
8. Підготувати базу даних PostgreSQL і схему основних таблиць.
9. Додати Docker-конфігурацію для запуску сервісів.
10. Перевірити працездатність проекту шляхом збірки та тестового запуску.

## Використані технології

У проекті використано такі технології:

1. React 18 - бібліотека для створення користувацького інтерфейсу.
2. TypeScript - мова програмування з типізацією для фронтенду.
3. Vite - інструмент для швидкої розробки та збірки фронтенду.
4. Tailwind CSS - CSS-фреймворк для стилізації інтерфейсу.
5. Motion - бібліотека для анімацій у React.
6. Lucide React - набір іконок для інтерфейсу.
7. FastAPI - Python-фреймворк для створення серверного API.
8. SQLAlchemy - ORM для взаємодії з базою даних.
9. PostgreSQL - реляційна система керування базами даних.
10. Docker і Docker Compose - інструменти контейнеризації та запуску сервісів.

## Архітектура проекту

Проект має клієнт-серверну архітектуру. Клієнтська частина відповідає за відображення сторінок, взаємодію з користувачем і надсилання HTTP-запитів до сервера. Серверна частина обробляє запити, виконує авторизацію, працює з базою даних і повертає відповіді у форматі JSON.

Основні частини проекту:

1. `frontend` - клієнтський застосунок на React.
2. `backend` - серверний застосунок на FastAPI.
3. `database` - SQL-схема бази даних.
4. `docker` - Dockerfile для фронтенду та бекенду.
5. `docker-compose.yml` - конфігурація для запуску сервісів.
6. `docs` - документація проекту.

## Опис клієнтської частини

Клієнтська частина реалізована як односторінковий застосунок. Основний компонент `App.tsx` керує переходами між сторінками, станом авторизації та збереженням даних користувача у `localStorage`.

Головна сторінка містить такі блоки:

1. Шапку сайту з навігацією.
2. Hero-секцію з візуальною презентацією магазину.
3. Блок популярних продуктів.
4. Блок переваг магазину.
5. Блок індивідуальної збірки.
6. Банер ігрового сетапу.
7. Відгуки користувачів.
8. Підвал сайту.

Для стилізації використовується Tailwind CSS. Анімації реалізовані за допомогою бібліотеки Motion. Іконки підключені через Lucide React. Такий підхід дозволяє створити сучасний, адаптивний і візуально привабливий інтерфейс.

## Опис серверної частини

Серверна частина реалізована за допомогою FastAPI. Вона містить маршрути для авторизації та роботи з даними користувача.

Основні маршрути API:

1. `GET /` - перевірка базової відповіді сервера.
2. `GET /api/health` - перевірка працездатності API.
3. `POST /api/auth/register` - реєстрація користувача.
4. `POST /api/auth/login` - вхід користувача.
5. `GET /api/users/me` - отримання даних поточного користувача.
6. `PATCH /api/users/me/avatar` - оновлення аватара користувача.

Для роботи з базою даних використовується SQLAlchemy. Дані користувача описані через модель `User`, яка містить ідентифікатор, ім'я, email, хеш пароля, аватар і дату створення.

## Авторизація і безпека

У проекті реалізовано базову систему авторизації. Під час реєстрації пароль користувача не зберігається у відкритому вигляді, а перетворюється на хеш. Під час входу система порівнює введений пароль із збереженим хешем.

Після успішної авторизації сервер створює JWT-токен. Клієнтська частина зберігає цей токен у `localStorage` і додає його до захищених запитів у заголовку `Authorization`. На сервері токен перевіряється перед доступом до маршруту профілю.

Такий підхід дозволяє відокремити публічні маршрути від захищених і забезпечити базову перевірку користувача.

## База даних

Для збереження даних використовується PostgreSQL. У проекті передбачена таблиця користувачів, а також SQL-схема для потенційного розширення магазину товарами, замовленнями та позиціями замовлень.

Основна сутність користувача містить такі поля:

1. `id` - унікальний ідентифікатор користувача.
2. `name` - ім'я користувача.
3. `email` - електронна пошта.
4. `password_hash` - хеш пароля.
5. `avatar_url` - посилання або дані аватара.
6. `created_at` - дата створення запису.

Використання PostgreSQL є доцільним, оскільки ця система керування базами даних підтримує надійне збереження структурованих даних, індекси, зв'язки між таблицями та масштабування.

## Запуск проекту

Для локального запуску фронтенду потрібно перейти до папки `frontend`, встановити залежності та запустити dev-сервер:

```bash
npm install
npm run dev
```

Для запуску бекенду потрібно перейти до папки `backend`, створити віртуальне середовище, встановити залежності та запустити сервер:

```bash
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

Також проект підтримує запуск через Docker Compose:

```bash
docker-compose up
```

## Перевірка працездатності

Працездатність клієнтської частини перевіряється командою:

```bash
npm run build
```

Працездатність Python-коду можна перевірити компіляцією модулів:

```bash
python -m compileall app main.py
```

Після запуску сервера додатково можна перевірити API через браузер, Postman або cURL:

```bash
curl http://localhost:8000/api/health
```
